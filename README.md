# Билеты ПДД 2026 (A, B)

Сайт для подготовки к теоретическому экзамену в ГИБДД: чистый HTML/CSS/JS, без сборки и сервера.

**Сайт:** https://daniillobastov.github.io/pdd-bilety/

## Режимы

- Экзамен как в ГИБДД: 20 вопросов по 4 тематическим блокам, 20 минут, дополнительные вопросы за ошибки, подтверждение ответа
- Серия экзаменов без повторяющихся вопросов, с допустимым числом проваленных экзаменов
- Билеты 1–40, вопросы по темам, марафон по всем 800 вопросам
- Работа над ошибками, избранное, сложные вопросы, случайные 20
- Статистика: прогресс по билетам и темам, история экзаменов, среднее время

Прогресс хранится в `localStorage` браузера.

## Запуск локально

Откройте `index.html` в браузере или запустите `python -m http.server 8765`.
